Active map: Map<threadKey, ChildProcess>. Max concurrent = formatterConfig.maxConcurrentProcesses (default 5).

Concurrency & Queue Logic ▶
  1. If queue exists for threadKey → push, await
  2. When dequeued → wait for active.size < maxConcurrentProcesses
  3. Call onStart() → spawn process
  4. On process close → shift next from queue, or delete queue

Messages to the same thread are sequential; different threads run in parallel up to the limit.

splitText Algorithm ▶

Splits at natural boundaries: newlines first, then spaces, then hard break. Each chunk gets [i/N] prefix. Reserves 12 chars for the prefix to stay within platform limit.

Reaction Pattern & Image Extraction ▶

Reaction: Strips [react:emoji] patterns from end of text. Multiple reactions supported. Returns cleaned text + string[] of emoji.

Images: Detects referenced image file paths in response text. Loads them as Buffer and wraps into Attachment[] for uploadFile().

flow Message Flow (8 steps) ▶
1
Receive

Adapter receives platform event → constructs IncomingMessage with normalized fields (platform, channelId, threadId, content, attachments)

2
Route

Router maps {platform}:{channelId} → project config. Checks for /im-* management commands. Returns null if channel not registered.

3
Thread

If threadId is null, create new thread. Discord: channel thread. Web: wb_project:timestamp. Async generates title via Claude (haiku model).

4
Persist

Save user message to DB. Create/update thread record. Send initial "⏳ Thinking..." indicator.

5
Invoke

SessionManager queues if thread busy, waits for concurrency slot (max 5), spawns claude --print --output-format stream-json --resume {sessionId} -p {message}.

6
Stream

Reads stdout NDJSON. Parses StreamInitEvent (session_id), StreamAssistantEvent (text + tool_use), StreamResultEvent (final + tokens). Calls onEvent.

7
Live Update

Accumulates bufferedText + activity log. setInterval (100ms web, 3s Discord) calls editMessage with current text + activity footer.

8
Format & Deliver

Extract [react:emoji], split text by limit, detect image paths, upload files, add reactions. Final message gets "✅ done [elapsed]" footer.

Startup Sequence (main())
  1. loadConfig(path)
  2. new Store(dbPath)
  3. SessionManager + Formatter + Router
  4. Init adapters (Discord if token, Lark if appId, Web if port)
  5. For each adapter: start() → setupProject() → registerChannel() → onMessage() → onReaction()
  6. cc2im ready
  7. Recover pending restarts from DB
  8. Register SIGINT/SIGTERM handlers
Graceful Shutdown
  1. Mark active threads as pending restart in DB
  2. sessionManager.abortAll() — SIGTERM all Claude processes
  3. adapter.stop() for each adapter
  4. store.close()
  5. process.exit(0)
AskUserQuestion Interception
  1. Stream callback detects tool_use block with name === "AskUserQuestion"
  2. Questions stored in lastAskQuestions
  3. After invoke completes, format questions and send to user
  4. Add entry to pendingAsks Map with a Promise resolve
  5. Next message from user in same thread resolves the promise
  6. Parse answer (letter combos like "AB" or full text)
  7. Re-invoke Claude with --resume + user's answer
