# Impeccable Design Guidelines

## Design Context

### Users
Developers and small teams using Claude Code for AI-assisted coding. They interact through Discord threads, a web UI, or a Tauri desktop app. The job: manage persistent AI coding sessions across projects with real-time streaming, token tracking, and multi-platform routing. Users are technical, efficiency-focused, and expect tools that stay out of their way.

### Brand Personality
**Geek · Refined · Composed** — Technical depth paired with attention to craft. The interface should feel like a precision instrument: confident, unhurried, and quietly impressive. Evoke trust and competence, not excitement.

### Aesthetic Direction
- **Visual tone:** Refined modern — tasteful restraint with intentional detail. Not minimal to the point of emptiness, not decorated to the point of distraction.
- **References:** Vercel (clean typography, generous whitespace, monochrome confidence), Raycast (information-dense yet elegant, purposeful use of subtle color accents).
- **Anti-references:** Overly colorful dashboards, cluttered dev tools with too many competing UI elements, generic Bootstrap/Material aesthetics.
- **Theme:** Dark mode default (Zinc neutral base). Light mode supported. Cyan (#4cc9f0) as the sole accent color — used sparingly for interactive elements and status indicators.

### Design Principles

1. **Quiet confidence** — Let content speak. Reduce visual noise. Use whitespace, typography hierarchy, and subtle contrast rather than borders, shadows, or color to create structure.

2. **Information density without clutter** — Developers value seeing data at a glance. Pack information efficiently but maintain breathing room through consistent spacing and clear grouping.

3. **Purposeful color** — The Zinc + Cyan palette is intentionally limited. Color means something: status, interaction, emphasis. Never decorative.

4. **Craft in the details** — Micro-interactions, transitions, and typographic polish distinguish a refined tool from a functional one. Subtle animations (opacity, transform) over flashy effects.

5. **Developer-native patterns** — Monospace where it matters (code, tokens, IDs). Keyboard-friendly. Respect conventions from tools developers already love (VS Code, terminal, Linear).

### Technical Foundation
- **Framework:** SvelteKit 2 + Svelte 5 ($state/$derived reactivity)
- **Components:** shadcn-svelte (New York style) + bits-ui
- **Styling:** Tailwind CSS 3 with HSL CSS custom properties
- **Icons:** lucide-svelte
- **Fonts:** System sans-serif stack, JetBrains Mono for code
- **Color system:** Zinc neutrals, Cyan accent (HSL 193 86% 63%)
- **Border radius:** 0.5rem default
- **Accessibility:** Ensure usable — sufficient contrast, keyboard navigation, semantic HTML. No strict WCAG compliance target.
